### **Ausgangslage**

Es gibt verschiedene Lösungen, um Backups zu erstellen. In einem ersten Schritt wollen wir mal nur ein paar einfache Daten auf unserem lokalen Rechner sichern.

---

## **Aufgabenstellung**

Halten Sie die Schritte der Teilaufträge mit Text und Bild fest.

### **Teilaufgabe 1: Auswahl der Software**

Wählen Sie eine Backupsoftware aus dem Link oben aus. Falls Sie eine andere SW kennen oder schon installiert haben, dann arbeiten Sie mit dieser SW. Wählen Sie nicht die Software Ashampoo. Sie hat einige Einschränkungen. Begründen Sie kurz die Wahl.

- Veeam Agent, Backup & Restore --> Nutzt das KMU meiner Eltern, Sichert Lokal und ist Ransomware geschützt, Datenwiederherstellung klappt per VEEAM OS welches sich per LAN / WLAN Treiber die Daten zurückholt. Schnelle Wiederherstellung möglich. 500GB in ca. 6 Stunden
### **Teilaufgabe 2: Daten auswählen**

Wählen Sie einige Daten aus, welche Sie sichern wollen. Achten Sie darauf, dass verschiedene Arten von Daten in diesem Set sind (Grafik, Dokumente, PDF, Textdateien, …). Erstellen Sie zwei verschiedene Sets von Daten (für die zwei verschiedenen Backupmedien). Sie können die Datengrösse auf 100 MiB beschränken.
![[Pasted image 20260316110907.png|425]]
### **Teilaufgabe 3: Backup auf Medien**

Bestimmen Sie zwei verschiedene Medien, auf die Sie ein Backup erstellen wollen. Bsp. USB-Stick, Externe Speicher, Netzwerklaufwerk, Cloud, (die eigene Disk)

- Erstellen Sie ein Vollbackup auf die beiden Medien
- Verändern Sie jeweils eine Datei (z.B. eine Worddatei). Vergleichen Sie das Archivattribut vor und nach der Veränderung.
- Erstellen Sie ein inkrementelles oder differentielles Backup auf die beiden Speichermedien.

Überprüfen Sie auf den Zieldatenträgern, ob ein Backup erstellt wurde.
