### **📌 Teilaufgabe 1: ZIP-Archiv verschlüsseln**  
📌 **Erstellen Sie ein verschlüsseltes Archiv mit 7-Zip.**  
1. Speichern Sie eine oder mehrere Dateien in einem **verschlüsselten Archiv**.  
2. Wählen Sie die Datei(en) aus und fügen Sie sie über das Kontextmenü (`rechte Maustaste`) zu einem neuen Archiv hinzu.  
3. **Dokumentieren Sie Ihre Einstellungen mit Screenshots.**  
4. Senden Sie das Archiv **inkl. Passwort** an den*die Lernpartner*in.  
5. **Entschlüsseln Sie das erhaltene Archiv** und dokumentieren Sie diesen Schritt mit Screenshots.  

---

### **📌 Teilaufgabe 2: Einen Datencontainer verschlüsseln**  
📌 **Erstellen Sie mit VeraCrypt einen verschlüsselten Container.**  
1. **Installieren Sie VeraCrypt** *(Sprache auf Deutsch umstellen: `Settings` → `Sprache` → `Deutsch`)*.  
2. Erstellen Sie ein neues Volume als **verschlüsselte Containerdatei** *(Standard VeryCrypt-Volume)*.  
3. Speichern Sie die Datei an einem sinnvollen Ort *(z.B. Moduldaten)*.  
4. Wählen Sie geeignete **Verschlüsselungseinstellungen** *(Benchmark-Vergleich möglich)*.  
5. Erstellen Sie eine **100 MB grossse Containerdatei**.  
6. **Erzeugen Sie ein sicheres Kennwort** und dokumentieren Sie dies.  
7. Formatieren Sie das Volume und erzeugen Sie einen Zufallswert durch **Mausbewegung** *(für sichere Verschlüsselung)*.  
8. **Mounten Sie das Volume im VeraCrypt-Manager** *(ein virtuelles Laufwerk erscheint)*.  
9. Speichern Sie **Beispieldateien** in das Volume und dokumentieren Sie dies mit Screenshots.  
10. **Trennen Sie das Volume im VeraCrypt-Manager**.  
11. Öffnen Sie die VeraCrypt-Datei in einem Editor – können Sie die Daten lesen?  
12. **Verbinden Sie den Container erneut** und zeigen Sie, dass die Daten entschlüsselt werden können *(dokumentieren mit Screenshots)*.  

---

### **📌 Teilaufgabe 3: Verschlüsselung der Cloud-Daten**  
📌 **Ermitteln Sie eine Methode zur Verschlüsselung von Cloud-Daten.**  
1. **Haben Sie Daten in der Cloud gespeichert?** *(Dropbox, GoogleDrive, iCloud, OneDrive …?)*  
2. **Recherchieren Sie eine Lösung**, um diese Daten zu verschlüsseln.  
3. **Dokumentieren Sie Ihre Lösung.**  

---

### **📌 Teilaufgabe 4: Auswirkungen Schlüsselverlust und Schlüsseltausch**  
📌 **Beschreiben Sie die Folgen eines verlorenen Schlüssels und die sichere Übertragung von Schlüsseln.**  
1. **Was passiert, wenn der Schlüssel verloren geht?**  
2. **Wie kann man dem vorbeugen?**  
3. **Wie kann der Schlüssel in Teilaufgabe 1 sicher ausgetauscht werden?**
