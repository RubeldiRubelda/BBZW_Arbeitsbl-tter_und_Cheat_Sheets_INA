Parameter-Typen im Überblick
In der Welt der Kommandozeile unterscheiden wir verschiedene Arten, wie wir einem Programm Informationen übergeben:

A. Named Parameter (Benannter Parameter)
Diese Parameter erwarten einen zusätzlichen Wert oder ein Argument. Man erkennt sie oft daran, dass nach dem Kürzel ein Name oder Pfad folgen muss.

Beispiel: mkdir -m 777 mein_ordner

Hier ist -m (mode) der benannte Parameter und 777 der Wert (die Berechtigung), den er erhält.

B. Switch Parameter (Flag / Schalter)
Ein Switch ist wie ein Lichtschalter: Er ist entweder AN oder AUS. Er braucht keinen extra Wert, seine bloße Anwesenheit verändert das Verhalten des Programms.

Beispiel: ls -l

Das -l (long format) ist ein Switch. Du sagst dem Programm damit nur: "Benutze das lange Listenformat". Es gibt keinen Wert, den du dem -l übergibst.

C. Positional Parameter (Positions-Parameter)
Diese Parameter haben keinen Namen oder Bindestrich davor. Ihre Bedeutung ergibt sich rein aus der Reihenfolge (Position), in der sie im Befehl stehen.

Beispiel: cp datei_a.txt datei_b.txt

Das Programm cp (copy) weiß durch die Position: Das erste Argument (datei_a.txt) ist die Quelle, das zweite Argument (datei_b.txt) ist das Ziel. Tauschst du sie vertauscht du die Logik.
